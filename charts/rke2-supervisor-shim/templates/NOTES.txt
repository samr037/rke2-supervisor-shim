rke2-supervisor-shim is installed on the control-plane nodes of {{ .Release.Namespace }}.

Verify it is serving:

  kubectl -n {{ include "shim.namespace" . }} get ds {{ include "shim.name" . }} -o wide
  kubectl -n {{ include "shim.namespace" . }} logs ds/{{ include "shim.name" . }} | grep advertising

Point a worker at it with an ORDINARY rke2 agent config - nothing bespoke:

  # /etc/rancher/rke2/config.yaml
  server: https://<control-plane-ip>:{{ .Values.supervisorPort }}
  token: <the token in secret {{ .Values.token.existingSecret }}>

node needs no change here - the DaemonSet will start a shim on it.

Prefer leaving it empty so control-plane nodes are discovered.
